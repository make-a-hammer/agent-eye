# agent-eye 升级设计：闲鱼选品数据分析模块

> 状态：设计稿（2026-08-06）
> 目的：用闲鱼真实交易信号替代拍脑袋选品，回答"什么标品好卖"
> 定位：trend_scout 的国内交易侧补充——trend_scout 看趋势（海外内容），本模块看交易（国内闲鱼）

## 一、为什么做

闲鱼是"低信任、先白嫖、只做量"的市场，定制服务（代找）赚不到钱。升级方向：**从"服务"转"标品"**，用数据选品。

- 现状：代找行业报告 → 3元/单、被白嫖、无法复制
- 目标：数据选出的标品 → 做一次卖一百次

## 二、数据源（已侦察，2026-08-06）

| 项 | 结论 |
|------|------|
| 网页版 | `goofish.com` HTTP 200 可访问，30 个分类全暴露 |
| 搜索接口 | `mtop.taobao.idlemtopsearch.pc.search`（h5api.m.taobao.com） |
| 门槛 | 需登录态 + mtop 签名（RGV587 风控） |
| 可行路线 | A: agent-eye Node.js worker 登录态渲染抓取（最稳）→ B: 抓 cookie 逆向签名（深度） |

## 三、分析框架

### 3.1 核心指标：需求量指数

```
需求量指数 = 该关键词总想要数 / 在售商品数

> 5   → 蓝海（供不应求，优先做）
1-5  → 正常市场，看价格带
< 1  → 红海，别碰
```

### 3.2 四信号表

| 信号 | 算法 | 回答 |
|------|------|------|
| 需求密度 | 商品数 + 平均想要数 | 有没有人买 |
| 需求强度 | 想要数/浏览数 | 真需求还是看热闹 |
| 供给缺口 | 想要数高但商品少 | 蓝海信号 |
| 价格带 | 成交价分布 | 定价空间 |

### 3.3 标题聚类（需求表述挖掘）

闲鱼标题是买家语言。聚类后看买家在找"文件"还是"服务"——决定卖 PDF 还是卖整理服务。

## 四、产品化漏斗

```
① 爬 30 关键词 × 前 20 条
② 算需求量指数 → 蓝海词
③ 价格带分析 → 定价
④ 标题聚类 → 设计产品/话术
⑤ 上架测试 7 天 → 验证
⑥ 有效放大 / 无效换词
```

## 五、已验证的选品假设（待数据确认）

| 假设 | 验证方法 |
|------|------|
| 行业报告整理能卖 | 搜"行业报告"看想要数/价格带 |
| 免费报告源清单能卖 | 搜"清单/资料包"看同类表现 |
| 换品类（考研/简历/模板） | 各搜一轮比需求量指数 |

## 六、法律与合规（对齐 ethics.py）

- 只爬**公开可见**的列表页数据（标题/价格/想要数），不爬用户私信、不爬成交明细
- 登录态只用于浏览公开页面，节流 + 日志（复用 ethics.py 的 throttle/log/detector）
- 分析结果用于自身选品决策，不批量导出他人商品数据转售

## 七、与 agent-eye 现有模块的关系

- `trend_scout.py` — 海外内容趋势（YouTube/Telegram/OpenBiliClaw）
- 本模块 — 国内交易信号（闲鱼），命名建议 `xianyu_scout.py`
- 共用 `ethics.py` 合规层、`eval.py` 决策记录
- 数据抓取走 `hand.py`（Node.js worker，登录态浏览器）
